Ethernet

Ethernet is a family of wired local area network (LAN) technologies standardized as IEEE 802.3, defining how devices format, transmit, and receive data frames over shared or switched media.

  • Frame-based protocol
  • Each endpoint has a unique ethernet address (MAC)
  • Frame include an FCS a CRC for error detection
  • No acknowledgement of packet delivery
  • Unreliable & packet loss possibility.
  • In-order delivery: not guaranteed end-to-end

OSI Layer

The OSI model (Open Systems Interconnection) organizes network communication into 7 layers.

Layer Name Main function Examples
7 Application User-facing network services HTTP, SMTP, DNS
6 Presentation Data format, encryption, compression TLS, JSON, JPEG
5 Session Session establishment and control RPC, NetBIOS
4 Transport End-to-end delivery, reliability, ports TCP, UDP
3 Network Routing across networks IP, ICMP
2 Data Link Framing, MAC addressing, local delivery Ethernet (802.3), Wi-Fi (802.11)
1 Physical Bits over the medium (signals, cables, radio) UTP, fiber, RF

IP (Internet Protocol)

  • Provides logical addressing and routing across interconnected networks.
  • Best-effort datagram delivery: no guarantee of delivery, ordering, or duplicate suppression.
  • Uses source/destination IP addresses and a TTL (hop limit) to prevent infinite forwarding loops.

Transmission Control Protocol (TCP)

  • Connection-oriented: endpoints establish state with a handshake before data transfer.
  • Full-duplex byte stream: both sides can send and receive concurrently.
  • Reliable delivery: retransmissions and acknowledgements recover from losses.
  • In-order delivery: sequence numbers ensure ordered reassembly.
  • Flow control: receiver window limits how much unacknowledged data the sender can transmit.
  • Congestion control: sender adapts rate to network congestion (fair-share behavior).
  • Header size: 20-byte minimum (without options) + checksum.

User Datagram Protocol (UDP)

  • Connectionless, message-oriented transport (datagrams).
  • No built-in reliability, ordering, or retransmission.
  • Low overhead and low latency; common in DNS, VoIP, streaming, and online games.
  • Checksum for error detection (mandatory in IPv6; optional but commonly used in IPv4).
  • Header size: 8 bytes.

La red como fuente de incertidumbre

  • Latencia variable: el tiempo de entrega cambia según carga, rutas y colas.
    • Timeouts and Unbounded Delays Preguntar a IA
  • Pérdida de mensajes: algunos paquetes no llegan al destino.
  • Duplicados: el receptor puede recibir el mismo mensaje más de una vez.
  • Reordenación: los mensajes pueden llegar en un orden distinto al enviado.
  • Particiones de red: grupos de nodos quedan temporalmente incomunicados.
